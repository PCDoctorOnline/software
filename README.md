# PC Doctor Online — System Diagnostic & Maintenance Toolkit

Official diagnostic and system optimization suite designed for automated PC maintenance, network health checks, and streamlined remote IT support.

## Key Features
* **Automated System Health Checks:** Real-time reporting on storage health, memory usage, and thermal performance.
* **Network & Connectivity Diagnostics:** Instant testing for DNS latency, ISP connectivity, and local gateway ping.
* **Malware & Junk File Cleanup:** One-click routines for temporary cache clearing and common threat scanning.
* **Remote Support Staging:** Secure, lightweight initiation for on-demand technical assistance via `pcdr.com.au`.
